# परिवार के लिए सेटअप (हिंदी)

यह शुरुआती build है। किसी बुज़ुर्ग के फोन पर लगाने से पहले परिवार का सदस्य खुद test करे।

1. Ask AI केवल official GitHub Releases से install करें और SHA-256 मिलाएँ।
2. Settings → Apps → Ask AI → Permissions में जरूरत के अनुसार Microphone दें। Contacts/Phone/SMS/Location जैसी permissions तभी दें जब उस feature का tested build उपलब्ध हो।
3. Settings → Accessibility → Installed apps/Downloaded apps → Ask AI को manually enable करें। Android 13/14+ में sideloaded app पर App info → ⋮ → Allow restricted settings दिखे तो पहले app/source जाँचें, फिर manually allow करें।
4. Settings → Notifications → Device & app notifications / Notification access में Ask AI को तभी enable करें जब notification reading का उपयोग करना हो।
5. Display over other apps में Ask AI को तभी allow करें जब floating orb वाला feature किसी future tested release में मौजूद हो।
6. Battery settings में unrestricted/background permission device manufacturer के निर्देशों से दें; हर फोन में menu अलग होता है।
7. अभी इस build में Family PIN, emergency contacts, medication schedules और SOS dispatch पूरा नहीं है। इन्हें उपलब्ध मानकर भरोसा न करें।
8. पहले सामान्य commands का परीक्षण परिवार के सदस्य के सामने करें। गलत समझे तो तुरंत “रुको” या “बस” कहें।
